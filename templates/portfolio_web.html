Création d'un outil web pour de la veille technologique, nommé Niche Watcher

Découvrez une application web de veille technologique hebdomadaire destinée à un public de professionnels souhaitant se tenir informés des dernières tendances et innovations dans le domaine de l'informatique.

Comprendre l’objectif du projet

Pourquoi Niche Watcher a été créé

À quoi sert ce projet ?

Niche watcher est un agrégateur de contenu pensé pour centraliser la veille des développeurs et professionnels de l’informatique. L'idée est simple : éviter de perdre du temps à consulter plusieurs sources séparément et recevoir à la place un résumé clair, automatisé et utile.

Le projet récupère des contenus depuis plusieurs sources techniques, les organise, puis les affiche sur une interface web simple et intuitive sur le site hebdomadairement. De plus, il recoit une newsletter par email pour informer les utilisateurs des nouvelles publications, s'il le souhaite.

Veille automatisée Centralisation des sources Gain de temps

Les statistiques techniques du projet

Les points techniques clés

Le projet repose sur une base technique compacte mais complète :

- Backend FastAPI pour exposer les endpoints, gérer l’authentification et servir les pages web.
- PostgreSQL comme base de données principale pour stocker les utilisateurs et les posts
- Scheduler Python exécuté de façon planifiée pour automatiser la collecte et l'envoie
- Sources RSS + Reddit pour agréger du contenu provenant de plusieurs flux dev
- Emailing pour envoyer la newsletter hebdomadaire aux utilisateurs inscrits

Le fonctionnement en images

Voici comment Niche Watcher transforme plusieurs sources en une veille claire et centralisée.

BeautifulSoup

1. Connexion des sources de contenu

Le système récupère les articles depuis des flux RSS techniques. On a css-tricks.com, hackernews.com et dev.to. Pour chaque, on récupère les 5 articles les mieux notés de la semaine et on effectue un top 15 global. De plus, les trois posts les mieux notés pour chaque flux sont affichés en tant que "A la Une"

Cette étape permet d’agréger automatiquement plusieurs points de veille sans intervention manuelle.

PostgreSQL

2. Stockage et organisation des données

Les contenus collectés sont enregistrés dans PostgreSQL avec les informations utiles pour le tri, l'affichage et le suivi.

La base contient aussi les données utilisateurs, comme l'adresse email, le token de connexion et l'état d'inscription à la newsletter.

JWT

3. Authentification des utilisateurs

Le projet propose un espace connecté avec inscrition, connexion et gestion du profil utilisateur.

Cela permet de personnaliser l'accès aux contenus et de gérer les préférences de diffusion de la newsletter.

Cron

4. Automatisation hebdomadaire

Un scheduler Python est exécuté chaque semaine pour collecter les contenus, les organiser et envoyer la newsletter aux utilisateurs inscrits.

Le but est de garder un système vivant sans dépendre d'une action manuelle quotidienne.

5. Diffusion de la newsletter

Les utilisateurs inscrits recoivent une synthèse des contenus sélectionnés directement dans leur boîte mail. Ils peuvent se désinscrire à tout moment via le bouton situé en plein milieu de la nav bar

Le projet ne se limite donc pas à afficher de l'information : il la transforme en expérience utile et récurrente
